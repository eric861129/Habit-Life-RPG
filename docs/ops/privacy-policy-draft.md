# Privacy Policy Draft

This draft is for the Habit Life RPG teaching project. It is not legal advice.

## Data collected

- Demo username
- Habit titles and categories
- Check-in timestamps
- Game progress fields such as level, EXP, gold, and HP

## Data not collected in this checkpoint

- Real name
- Payment data
- Precise location
- Contact list
- Production OAuth profile

## Usage

The data is used only to demonstrate habit tracking, reward calculation, API testing, deployment, and monitoring workflows for the book.

## Retention

Demo data may be reset at any time. A real production product must define retention and deletion rules before launch.
