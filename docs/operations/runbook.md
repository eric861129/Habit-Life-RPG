# Habit Life RPG Runbook

## 健康檢查

- `/health/live`：確認應用程式程序仍可回應。
- `/health/ready`：確認應用程式能連接資料庫。

## 變更後驗收

1. 確認部署版本與預期commit/tag一致。
2. 執行資料庫migration。
3. 驗證註冊、登入、受保護請求與Token失效。
4. 驗證Habit建立、優先級排序、修改、封存與每日打卡。
5. 發生異常時先保留時間、版本、路徑、狀態碼與去識別化Log。

## 停止與升級條件

- migration無法完成或資料結構與文件不一致。
- 大量 `401`、`409` 或 `5xx` 與預期基準不同。
- 發現機密、個資或跨使用者資料風險。

遇到以上情況時停止繼續發布，保留現場證據並交由維護者判斷復原或修正。
