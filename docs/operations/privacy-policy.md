# Habit Life RPG 公開示範環境隱私政策

生效日期：2026-07-11

## 適用範圍

本政策適用於書籍《左手藍圖，右手魔法》的 Habit Life RPG 公開教學網站與 API。此服務是無 SLA 的示範環境，不適合保存個人、機密、醫療、財務或其他敏感資料。

## 我們處理的資料

- 帳號：使用者名稱，以及經 Argon2 單向雜湊後的密碼。系統不保存可讀的原始密碼。
- Habit：標題、描述、分類、封存狀態、連續天數與最近打卡日期。
- Check-in：日期、時間、經驗值、金幣與等級結果。
- 技術資料：Microsoft Azure 可能為提供服務與安全維運處理 IP 位址、User-Agent、請求時間與平台診斷紀錄；這些資料不寫入 HLR 的業務資料表。

系統不使用廣告追蹤或第三方分析 SDK。登入後的 JWT 會保存在使用者瀏覽器的 `localStorage`，預設有效期為 60 分鐘；登出會移除該 token。Azure App Service 可能設定平台負載平衡 Cookie。

## 使用目的

資料只用於驗證登入、管理 Habit、處理每日 Check-in、計算示範用的 streak／經驗值／金幣，以及維護服務安全與可用性。資料不出售，也不拿來投放廣告。

## 保存與刪除

這是教學環境，資料可能因維護、重建、免費配額或專案結束而被清除，不提供永久保存保證。Habit 的刪除操作目前是封存；目前沒有自助刪除整個帳號的介面。需要刪除帳號時，請透過 [專案維護者的 GitHub 頁面](https://github.com/eric861129) 聯絡，且不要在公開 Issue 張貼密碼、Habit 內容或其他敏感資料。

## 服務供應商與處理區域

前端、API 與資料庫由 Microsoft Azure 提供；目前 App Service 與 Azure SQL 位於 `westus2`，Static Web Apps 亦建立於 West US 2。原始碼、CI/CD 與唯讀健康探測由 GitHub 提供。使用者應在接受這些跨區域雲端處理方式後再使用示範服務。

## 公開示範帳號

`book-demo` 是所有讀者共用的帳號，任何登入者都可能看到或變更其中內容。請勿在該帳號輸入任何個人資料。需要隔離資料時，請註冊自己的教學帳號，但仍不要存放敏感資料。

## 安全與政策變更

服務使用 HTTPS、密碼雜湊、短效 JWT、最小 CORS 清冊與受限部署權限。網路服務仍無法保證絕對安全。政策有重大變更時，會在公開 Repository 的版本紀錄中更新生效日期與內容。
