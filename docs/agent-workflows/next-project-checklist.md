# Next Project Checklist

1. Define the user and problem.
2. Write the first PRD.
3. Convert the PRD into user stories and acceptance criteria.
4. Draw the UX flow.
5. Draft UI spec and API contract.
6. Create a safe repository with `.gitignore` and `.env.example`.
7. Build the smallest backend path.
8. Add tests before broadening features.
9. Build the frontend against real API responses.
10. Prepare deployment templates without secrets.
11. Add monitoring, runbook, and privacy notes before launch.
12. Tag each chapter or milestone.
