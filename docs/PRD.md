# Habit Life RPG PRD

版本：Book v2 / Chapter 3

狀態：MVP 產品契約

## 1. 產品願景

Habit Life RPG 把每天想完成的習慣轉換成一段看得見的角色成長旅程。使用者完成現實生活中的行動後，在產品內每日打卡，立即得到經驗值、金幣、連續天數與等級回饋。

本專案同時是《左手藍圖，右手魔法》的累進式範例。每個章節分支都必須讓讀者理解「產品規格如何逐步變成可測試、可部署的軟體」。

## 2. 問題與目標使用者

目標使用者是想建立穩定生活習慣，卻容易因回饋太慢而中斷的人，以及希望學會文件驅動 AI 開發流程的讀者。

產品解決三個問題：

- 習慣完成後缺少即時且可累積的正向回饋。
- 一般待辦工具只記錄完成，無法呈現長期成長感。
- AI 開發示範常只留下最終程式碼，讀者看不到產品決策如何影響架構與測試。

## 3. 本書 MVP

本書 MVP 必須完整包含：

- 使用者註冊、登入與登出。
- 個人資料與登入狀態管理。
- 習慣 CRUD：建立、查看、修改與封存自己的習慣。
- 每日打卡與同日重複打卡防護。
- 依照本地日期計算連續天數。
- 打卡成功後增加金幣、經驗值與等級。
- 個人 Dashboard 顯示今日狀態、可執行習慣與最近成果。
- mobile 與 desktop 響應式介面。
- loading、empty、success 與 error 狀態。
- 本機 SQLite、正式 Azure SQL、自動測試與 Azure 免費層部署。

## 4. 核心產品規則

### 4.1 使用者與資料所有權

- 帳號名稱不分大小寫重複註冊。
- 密碼只保存安全雜湊，不保存明文。
- 使用者只能讀寫自己的 Profile、Habit 與 Check-in。
- 查詢不存在或不屬於登入者的 Habit，對外都回傳 `404`，避免洩漏他人資料是否存在。

### 4.2 習慣生命週期

- 新 Habit 必須有 1～120 字的名稱。
- 描述與分類可以留空。
- 封存後不出現在今日任務，但歷史打卡仍保留。
- 已封存 Habit 不可再次打卡，除非先恢復為啟用狀態。

### 4.3 每日打卡

- 一個 Habit 在應用程式時區的同一曆日只能成功打卡一次。
- 每次成功打卡建立一筆不可重複的 Check-in 紀錄。
- 重複請求回傳 `409 Conflict`，不得再次發放獎勵。
- 日期邊界統一使用 `HLR_APP_TIMEZONE`，預設為 `Asia/Taipei`。

### 4.4 Streak 與獎勵

- 昨天曾打卡同一 Habit，今天成功打卡時，連續天數加一。
- 上次打卡早於昨天，今天成功打卡時，連續天數重設為一。
- 每次成功打卡固定得到 `+40 EXP` 與 `+8 gold`。
- 升級門檻為 `level × 200`。
- 達到門檻時等級加一；EXP 保留為累積總值，讓規則容易解釋與測試。
- 所有獎勵由後端交易一次完成，前端只能呈現結果。

## 5. 核心旅程

1. Guest 建立帳號或登入。
2. Member 進入 Dashboard，看見角色摘要與今日習慣。
3. Member 建立或調整 Habit。
4. 完成現實行動後，Member 對 Habit 送出每日打卡。
5. 後端驗證登入、資料所有權、封存狀態與重複日期。
6. 後端建立 Check-in、更新 Streak、EXP、gold 與 level。
7. 前端顯示成功或升級回饋，並更新 Dashboard。

## 6. 成功標準

- 新讀者能在五分鐘內完成註冊、建立第一個 Habit 與第一次打卡。
- 同日連續送出兩次打卡，只會產生一筆 Check-in 與一次獎勵。
- 主要流程在 390 × 844 與 1440 × 1000 viewport 都能完成。
- 所有核心 API 有自動測試，前端核心流程有元件測試與 E2E。
- 公開 Demo 不需讀者登入 GitHub 即可開啟。

## 7. 非功能需求

- **安全**：JWT 有效期有限、密碼使用 Argon2、CORS 使用明確來源、Secret 不進 Git。
- **可及性**：表單具可見 label，錯誤可由輔助科技讀取，鍵盤能完成核心操作。
- **效能**：一般 API 在免費層暖機狀態下應於合理時間回應，冷啟動需有 loading 與重試提示。
- **可靠性**：資料庫唯一約束是重複打卡的最終防線。
- **可教學性**：每個章節分支都有安裝、執行、測試與限制說明。

## 8. 不在本書 MVP

Boss 戰、商店、道具、社交排名、大型任務鏈、付費功能、多人協作與原生手機 App 不在本書 MVP。這些可作為讀者延伸題，但不得阻礙主線交付。
